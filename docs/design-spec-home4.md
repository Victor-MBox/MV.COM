### 3.3 Правила, которые на `/home4` читаются иначе

1. **Фото в hero разрешено** (как на `/home2`): это сигнатура Portilo. Тогда блок для HR (6.7) — без фото. Фото на странице по-прежнему одно.

3. **Главная CTA hero — язычок (5.1), а не круглая кнопка.** Акцентные кнопки на странице: язычок hero, «Все работы» в 6.4, «Обсудить проект» в 6.9. На одном экране — не больше одной.

## 4. Шапка `TopHeader`

Компонент `src/components/topHeader/TopHeader.tsx` + `.scss`. Рендерится в `App` вместо `LeftMenu` на маршруте `/home4` (4.5).

### 4.1 Десктоп (≥992)
- `<header>` `position: sticky; top: 0; z-index: var(--z-menu)`, высота `--header-h`, на всю ширину окна; внутри контейнер 1320px с гаттерами 1.0.
- **Слева** — слово-логотип: «Victor Matsakov» и точка `--accent` после него (как «Portilo.»), Geologica 500 18px, трекинг −0.02em, цвет `--text`. Ссылка на `/home4` (после принятия варианта — на `/`). Вариант «Мацаков.» — решает владелец.
- **По центру** — `<nav aria-label="Основное меню">` с четырьмя ссылками: Услуги `/services` · Портфолио `/portfolio` · Обо мне `/about` · Контакты `/contacts`. Golos 500 15px, цвет `--text-muted`, ховер `--text` за 180 мс. Активная — `--text` и точка 4px `--accent` по центру под текстом (та же роль маркера, что у точки в `LeftMenu` 1.0). Пункта «Главная» нет — это логотип. Расстояние между ссылками 32px.
- **Справа** — `ThemeButton` (рестайл в скоупе: круг 40px, стекло `--glass` + `--glass-border`, иконка 18px `currentColor`, поворот 180° за 360 мс при смене темы) и кнопка «Обсудить проект» — `Button variant='secondary'` высотой 44px (стекло, как «Contact» у Portilo; без свечения). Открывает модалку с `LeadForm`.
- Над hero шапка прозрачная. После прокрутки на 24px — фон `color-mix(in srgb, var(--bg) 85%, transparent)`, `backdrop-filter: blur(12px) saturate(140%)`, нижняя граница 1px `--border`; переход 240 мс. Состояние — класс `topHeader--scrolled`, считается по событию `scroll` Lenis (или `window` при `reduced-motion`) через `requestAnimationFrame`.
- Шапка не прячется при прокрутке вниз.

### 4.2 Мобильные и планшеты (≤992)
- Ссылки и кнопка «Обсудить проект» скрыты. Справа — **круглая кнопка-меню** 40px (стекло), внутри 4 точки 3px `--text` квадратом 2×2 (как у Portilo). `aria-expanded`, `aria-controls="menu-overlay"`, `aria-label="Открыть меню"`. При открытии точки за 240 мс сходятся в «×» (две точки по диагонали растягиваются в линии, две другие гаснут).
- **Полноэкранная панель** `role="dialog" aria-modal="true"`: `position: fixed; inset: 0`, фон `color-mix(in srgb, var(--bg) 96%, transparent)` + `blur(12px)`. Содержимое: пять пунктов столбиком (Главная + четыре ссылки) с номерами `01–05` в моно `--text-muted` слева, пункты — 3.2; появление `opacity 0→1, y 16→0` за 360 мс со стаггером 40 мс; под ними ряд: `ThemeButton`, e-mail и Telegram из `CONTACT_LINKS` (моно 14px). Переход по ссылке закрывает панель.
- Ловушка фокуса, возврат фокуса на кнопку, Esc закрывает, фон не прокручивается (`lenis.stop()` + `overflow: hidden` на `body`). На ≤768 высота шапки 56px.

### 4.3 Плавающая панель соцссылок (≥1200)
- У правого края окна, по вертикали по центру, `position: fixed`, `z-index: var(--z-sticky)`: стекло `--glass` + бордер `--glass-border`, радиус `12px 0 0 12px`, ширина 44px, три иконки 20px столбиком с отступом 16px: GitHub, Telegram, LinkedIn (`CONTACT_LINKS`, SVG `currentColor`, цвет `--text-muted`, ховер `--text`), каждая с `aria-label`. Скрыта на ≤1200 и пока открыто мобильное меню. Решение владельца: панель можно отключить — компонент принимает `links` и не рендерится при пустом массиве.

### 4.4 Пропуск к содержимому
Первым элементом в DOM — ссылка «К содержанию» на `#hero`: скрыта, появляется по `:focus-visible` в левом верхнем углу (кнопка primary).

### 4.5 Изменения каркаса приложения
- `src/app/routes.ts` (новый): `V2_ROUTES = ['/home3', '/home4']`, `isV2Route(pathname)`, `isTopHeaderRoute(pathname)` (`/home4`). Условия в `App`, `ContactModal`, `ScrollToTop`, `LeftMenu` переводятся с `pathname === '/home3'` на эти функции.

## 5. Новые компоненты

Соглашение 1.0: `src/components/<name>/<Name>.tsx + .scss`, состояния и движение описаны здесь, токены — только из таблиц.

### 5.1 Кнопка-язычок (`TabCta`)
Главная CTA hero, сидит на нижней кромке секции по центру (у Portilo — «Hire Me»).
- Размер 240×52px; форма — трапеция со скошенными верхними углами: `clip-path: polygon(0 100%, 7% 0, 93% 0, 100% 100%)`; заливка `--accent`, текст `--on-accent`, Geologica 500 16px. Позиция `position: absolute; bottom: 0; left: 50%; translateX(-50%)`.
- Ховер: `--accent-hover`; нажатие `scale(.98)` 120 мс; фокус-кольцо 1.0 (`outline-offset: 4px` поверх `clip-path` не видно — кольцо рисуется псевдоэлементом вокруг родителя-обёртки без `clip-path`).
