## 6. Живая обложка — набор `rgs` для `FloatingPreview`

### 6.1. Идея и правила владельца

Как у NoRandoms: на сцене 16:10 парят настоящие элементы продукта на разной глубине, покачиваются, сдвигаются за курсором,
проявляются по очереди. Правила владельца для обложек (обязательные):

- **Только живая вёрстка** для элементов интерфейса: реплика и панель — HTML и стили игры, а не скриншоты. Ужатые
  скриншоты «мылятся» — владелец это уже отверг.
- Картинки допустимы там, где в игре они и есть картинки: персонаж, подарок, иконки (исходные ассеты игры с прозрачностью).
- Надписи — фирменным шрифтом игры.
- Чувство меры: не больше шести слоёв, один главный.
