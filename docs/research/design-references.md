# Визуальные референсы: сайты частных разработчиков и малых студий

Дата: 19 октября 2026. Задача: найти сайты, которые одновременно красивые и продающие — ясные акценты в тексте и дизайне, ничего не сливается. Эталон от владельца: https://xhuman.ru/.

Метод: четыре параллельных поиска (международные соло-разработчики, малые студии и дуэты, русскоязычный рынок, «паттерн xhuman» + готовые шаблоны-системы). Источники: Awwwards, Godly, Siteinspire, Land-book, Minimal Gallery, Dark Mode Design, Framer/Webflow marketplace, Dprofile/Behance. Проверено ~90 адресов, в отчёт вошло 45 живых сайтов и 6 шаблонов. Каждый открыт WebFetch/curl 19.10.2026; шрифты, цвета и библиотеки вытащены из HTML/CSS, а не из рендера — это косвенный вывод, перед копированием приёма смотреть в браузере. Сайты из `competitors-intl.md` и `competitors-ru.md` сюда не включались.

## 0. Главный вывод

**Шрифты у MV.COM не проблема.** xhuman.ru набран Geologica (заголовки) + Manrope (текст) — та же Geologica, что уже стоит на главной. cheg.dev использует Golos UI. Разница с эталоном — в четырёх вещах:

1. **Нет единого знака акцента.** Сейчас синий работает и как слово в H1, и как текстовые ссылки, и как номера шагов, и как подпись кейса, и как градиент плитки оффера; рядом оранжевый градиент второй плитки, зелёная точка, синие и оранжевые свечения карточек. У сильных сайтов один приём на весь сайт (цветное слово / курсив / «↪ фраза» / «[ скобки ]») и один цвет ровно в трёх местах: акцентное слово, главная кнопка, цифры.
2. **Нет моно-слоя для служебного текста.** Нумерация секций «01–05», теги стека, подписи к цифрам, время, коды — везде моношрифт (Geist Mono, JetBrains Mono, IBM Plex Mono, Iosevka). Это и даёт «ничего не сливается»: заголовки не конкурируют с мелочью.
3. **Цифры с подписью в hero.** 3–4 факта в ряд: число + суффикс + подпись в одну строку (60+ Projects · 9Y · 14 дней · 5/5). Одна про срок, одна про качество. Цифра может быть первым словом H1.
4. **Движение — ритм, а не шоу.** Единый стек: Lenis-скролл + reveal по скроллу + одна бегущая строка (стек или клиенты) + счётчики; SplitText только на hero; курсоры-ярлыки только там, где несут смысл. WebGL — только у show-портфолио, и там мешает читать.

Плюс два коммерческих приёма, которые есть почти у всех продающих: **статус «Открыт для проектов» + CTA на 15-минутный звонок прямо в hero**, и **цена «от» / диапазон со сроком на главной** (часто внутри FAQ).

## 2. Сквозные правила, которые повторяются во всех четырёх подборках

1. **Одно акцентное слово на заголовок, и оно несёт оффер** («everyone», «full-service», «event technology», «founders»), а не прилагательное. Правило держится на всех H2 страницы, не только в hero.
2. **Один приём акцента на весь сайт**: либо курсив, либо цвет, либо жирный, либо знак («↪», «[ ]»). Два приёма сразу — только в шаблонах, и выглядит дешевле.
3. **Цвет акцента живёт в трёх местах**: акцентное слово, основная кнопка, цифры/иконки. Фон и 90% текста нейтральные: глубокий чёрный или крем, не «серо-синий». У xhuman: #23202d + один жёлтый #F4BF4F; коралл только для «боли».
4. **Пара «дисплей/гротеск + моно»**: моно берёт нумерацию, теги, подписи, время. Где шрифтов четыре — «сливается».
5. **Цифра = число + суффикс + подпись в одну строку**, 3–4 в ряд. Подпись может быть целым предложением-доказательством («только 5% кандидатов допускаем к работе»). Нигде нет «100% довольных клиентов».
6. **Порядок страницы у коммерчески сильных**: hero с одним CTA и статусом → полка доказательств (цифры / логотипы / награды) → проблема клиента → услуги → процесс 3–4 шага → кейсы с результатом в заголовке → отзывы → цена «от» / оффер → FAQ → финальный CTA с бронированием.
7. **Мотив живого человека**: «Open for work», местное время, фото и имя, «You work directly with me», «Yes, just me».
8. **Бегущие строки — только для логотипов, наград или тегов стека**, не для текста.

### Что брать из sprocket #services и Zolt #work
- **sprocket, услуги:** заголовок секции между двумя линиями-разделителями, затем карточки услуг = h3 + одна строка описания + **мини-интерфейс из настоящих HTML-элементов** (у лендинга — заголовок и кнопка «Get profit», у сайта — карточка статьи с датой, у каталога — панель фильтров с чекбоксами). Свечение рамки `glow-border` одного цвета. Для MV.COM: 7 офферов → 3 крупные карточки с мини-интерфейсом + 4 компактные строки, иллюстрация в акцентном цвете только одним элементом.
- **Zolt, работы:** метка «// Featured works» + подзаголовок, карточка = заголовок с результатом («Redesigning the Core Dashboard…») · срок («3 month») · год · абзац с одной цифрой («cut user drop-off by 40%») · клиент · роль. Для MV.COM: NoRandoms = «6 000+ пользователей» в заголовке, срок, год, роль «full-stack, соло». Блок «// Stacks & Experience» (01–04, годы, теги стека, одна строка результата) — готовый формат «Для HR».

### Скелет главной
1. Hero: пилюля «Открыт для проектов с ноября» → девиз в две строки → сетка 7/5: слева теги с коралловыми точками (сайты · веб-приложения · интеграции) и H1-абзац с одной коралловой строкой, справа круглая кнопка «Обсудить проект» → ряд из трёх цифр с подписями.
2. «// услуги» — 3 карточки с мини-интерфейсом + 4 строки.
3. «// работы» — карточки по Zolt, первая широкая.
4. «// как работаю» — 4 шага аккордеоном с пригашиванием соседей (OKC).
5. «// для HR» — опыт 01–04 с тегами стека и строкой результата (Zolt).
6. Четыре счётчика (Portilo) → бегущая строка «Давайте работать →» → форма с выбором намерения (проект / вакансия / вопрос).

### Токены (стартовые значения)
`--bg #161616 · --box #1c1c1c · --box-hover #111 · --text #fefefe · --text-body rgba(255,255,255,.8) · --text-muted #808080 · --dim #323232 · --border rgba(255,255,255,.12) · --accent` — один из двух: #f07077 (OKC, спокойнее, лучше в светлой теме) или #ff4625 (Portilo, горячее). Типографика: девиз `clamp(2.2em, 12vw, 5.2em)` / 0.95 / −0.1rem / 500; заголовок секции `clamp(32px, 3vw, 40px)` / 1 / −0.02em / 500; лид `clamp(1.5rem, 2.7vw, 1.8rem)`; метка `clamp(.75rem, 1.4vw, 1rem)` / 0.08em / моно; текст 1rem / 1.61. Движение 360 мс `cubic-bezier(.2,.7,.2,1)`, стаггер 25–100 мс.

### Не брать из Portilo
Skill-bars с процентами, Tektur и Zen Dots, переключатель цен «месяц/год», шесть одинаковых отзывов, имя как H1 (H1 — оффер, имя — в девизе или статусе), заглушки «0+» в счётчиках.

## Сквозные паттерны «акцентное слово + большая цифра»
1. **Одно акцентное слово на заголовок — и оно несёт оффер** («everyone», «full-service», «event technology», «founders»), а не прилагательное. jaro и designjoy держат правило на всех H2 страницы.
2. **Один приём акцента на весь сайт**: либо курсив, либо цвет, либо жирный. Два приёма сразу — только в шаблонах, и выглядит дешевле.
3. **Цвет акцента живёт в трёх местах**: акцентное слово, основная кнопка, метрики/иконки. Фон и 90% текста нейтральные. У xhuman: #23202D + один жёлтый #F4BF4F; коралл — только для «боли».
4. **Цифра = число + суффикс + подпись в одну строку** (60+ Projects, 9Y Experience, 4.7/5). 3–4 в ряд: одна про скорость/срок, одна про качество. У xhuman и omnystudio подпись — целое предложение-доказательство. Цифра может быть первым словом H1.
5. **Ритм секций одинаков**: hero с одним CTA → доказательство → проблема → услуги → процесс 3–4 шага → кейсы с метрикой → отзывы → цены/оффер → FAQ → финальный CTA. Бегущие строки — только для логотипов/тегов, не для текста.
